How testing works

  1. Copy your Saves folder before each batch.
  2. Delete localthumbcache.package and old lastException files from Documents\Electronic Arts\The Sims 4, then launch and load the save.
  3. Run the batch's checks. A pass means no error pop-up and no new lastException file.
  4. If something fails, see When a mod breaks. If it passes, log the versions in the Tracker.

After every patch

  1. Turn Script Mods Allowed back on in Game Options, Other. EA resets it.
  2. Check the EA Forums "Broken and Updated Mods" thread for the new patch.
  3. Update the mods that need it and delete their old files.
  4. Delete localthumbcache.package.

When a mod breaks

  1. Check that Script Mods Allowed is on and the mod has a build for your game version.
  2. Delete old or duplicate copies of the mod, then delete localthumbcache.package.
  3. Open the newest lastException file and look for a mod's name in it.
  4. Still stuck: move half your mods out, test, and keep halving the half with the problem. Keep each mod with the mods it needs.
