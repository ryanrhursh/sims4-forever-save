Sims 4 Install Order

A batch-by-batch install plan for a modded forever world on PC, built around a restaurateur who gardens on the side. Add one batch, load your save, then tick the test gate before you move on.

Mods go in Documents\Electronic Arts\The Sims 4\Mods. Researched from creator pages and EA forum threads on October 9, 2026, when patch 1.128 was current. I could not confirm that every mod has a 1.128 build, so open each mod's own page and use the build it lists for your game version.

How testing works

Every batch ends with a test block. Pass it before you add the next batch.

  1. Copy your Saves folder before each batch, and again after the batch passes. The second copy is your known-good point.
  2. Run the rows in order: a clean start, the tasks for the mods you just added, then the wrap-up.
  3. A pass means no error pop-ups, no new lastException file, and every task did what the mod's page says it should.
  4. If a task fails, move that batch's files out of Mods, delete localthumbcache.package, and confirm the problem is gone. Add the files back one or two at a time. The steps are in When a mod breaks.
  5. Log the result in your tracker workbook, so you can see later which build you tested.

After every patch

Do these in order each time EA updates the game.

  1. Turn Script Mods Allowed back on in Game Options, Other. EA resets it.
  2. Read the new version number at the bottom right of the main menu.
  3. Check the EA Forums broken and updated mods thread for that patch.
  4. Update every mod that needs it and delete the old files, so no duplicates remain.
  5. Delete localthumbcache.package from the Documents\Electronic Arts\The Sims 4 folder.
  6. If the game still errors, move half your mods out, test, and repeat on the half that breaks it.

When a mod breaks

Work down this list and stop as soon as the problem goes away.

  1. Turn Script Mods Allowed back on in Game Options, Other. EA resets it with each patch, and it is the most common reason script mods go quiet.
  2. Compare your game version with the EA forum thread for the current patch. If the mod is listed as broken, update it or remove it.
  3. Delete old and duplicate files. After an update, the previous version has to be gone, including copies in other subfolders.
  4. Delete localthumbcache.package from the Documents\Electronic Arts\The Sims 4 folder, then launch again. Do this every time you change what is in Mods.
  5. Run a vanilla test. Move the whole Mods folder to your Desktop and launch. If the problem stays, a mod is not the cause. If it goes away, one is.
  6. Find the culprit with the 50/50 method below.
  7. Write down what you found in the Issue Log of your tracker workbook.

The 50/50 method

  1. Move half of your mod files out of Mods into a holding folder on your Desktop. Keep a script mod together with the files it needs, such as XML Injector for Seasonal Emotions.
  2. Delete localthumbcache.package, launch, and load your save.
  3. If the problem is gone, the culprit is in the half you moved out. If it is still there, it is in the half that stayed.
  4. Split the half that holds the culprit and repeat until one mod is left.
  5. Update or remove that mod. Move the others back in small groups, testing after each group.

Common symptoms

What you seeLikely causeWhat to do
A script mod does nothing after a patchScript Mods Allowed was reset, or the mod has no build for the new patch.Re-enable the setting, then check the mod's page for a build that matches your game version. Some mods run on their own and show no pie menu by design.
A script mod never loadsIts .ts4script file sits more than one folder deep.Move it into Mods or one subfolder inside Mods.
Chefs or waiters stop working after a patchEA changed how worker shifts are set up. Dine Out Reloaded can get blamed when another mod that touches shifts is out of date.Update Dine Out Reloaded and any other restaurant or career mod. Check Carl's mod status post for the patch.
Body parts look stretched or distortedNisa's Wicked Perversions does not match your WickedWhims release, or an old rig or body mod is still installed.Install the Wicked Perversions release that matches your WickedWhims version and delete outdated rig and body mods.
Pregnancy behaves oddlyWhims pregnancy overrides MCCC pregnancy by default.Turn the override off in the Whims settings if you want MCCC in charge.
Duplicate items or odd behavior after an updateThe old version of the mod is still in Mods.Search Mods for the mod's name and delete the older files.
An error pop-up appearsA script mod threw an error. The game writes lastException files into the Documents\Electronic Arts\The Sims 4 folder.Open the newest lastException file, look for a mod's name in the file paths, then update or remove that mod.
The game will not start, or shows a white screenA broken mod or CC file.Run the vanilla test, then the 50/50 method.
